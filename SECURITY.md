# Security Policy

## Supported Versions

Security updates are provided for the latest released version of Storage Unit Converter.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If GitHub Private Vulnerability Reporting is enabled for this repository, please use it to report security issues privately.

When submitting a vulnerability report, please include as much relevant information as possible, such as:

- A description of the vulnerability
- Steps required to reproduce it
- The affected version
- The potential impact
- Any suggested remediation, if known

Please avoid publicly disclosing the vulnerability until it has been reviewed and, when necessary, fixed.

## Scope

Security reports should concern vulnerabilities directly related to the Storage Unit Converter application or its distributed packages.

General feature requests, usability issues, and non-security bugs should be reported through the regular GitHub issue tracker.
